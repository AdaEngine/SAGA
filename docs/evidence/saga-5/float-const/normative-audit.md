# Scalar floating const expressions and scalar alias constructors

Reference pin: a55352911bb26a1b33bc8d5fc03bdebb0a967f5a, read-only. This is independently authored Swift code/tests, not Rust FFI or runtime dependency. All new test sources are independently authored literals. Shared IR, raw validator, private witness and frozen baseline are unchanged.

## Audit before the grammar/representation changes

Pinned `docs/sources/wgsl-spec.bs` defines AbstractFloat as the finite IEEE binary64 set (#abstract-numeric-types). Arithmetic in abstract numeric types must not overflow or produce infinity/NaN. The f32 type uses binary32. #floating-point-evaluation/#floating-point-rounding-and-overflow requires shader-creation errors for evaluated const intermediates yielding infinity/NaN; it does not permit blindly replacing all const f32 arithmetic by binary64 with one final conversion. Rounding to nearest is one allowed choice, not a mandated universal rounding mode. #floating-point-conversion requires finite-range checks for const conversions and float-to-integer clamping/truncation to a value ALSO representable in the source format. Thus f32->u32 upper bound4294967040, and f32->i32 upper bound2147483520, differ from the integer maxima. AbstractFloat->integer can reach the integer maxima because binary64 represents them exactly.

Pinned `naga/src/proc/constant_evaluator.rs` uses distinct typed F32 and AbstractFloat/F64 operations, checking finite results; float modulo uses the host floating remainder. The prior integer/bool whole-tree validation/lazy evaluation audit remains in force. Integer division, shifts, implicit type conversions and clamp retain mandatory creation-time checks even on skipped branches; ordinary skipped floating arithmetic/conversion need not be evaluated when no separate check requires it. This implementation does NOT repeat the pinned Naga logical() TODO that omits RHS type-checking.

Constructor/type aliases are synonyms, not textual substitutions: existing declaration indexing and cycle resolution can resolve an alias to scalar bool/i32/u32/f32 before selecting the scalar overload. Module values and nearer local constants/parameters must shadow the callable alias. Alias cycles, non-scalar targets and wrong arity fail closed. This needs no IR schema/validator change. f16/aggregate constructors remain unsupported rather than being silently mapped to f32/scalars.

## Implementation

`FloatingConstants.swift` adds explicit abstract/f32 kind and numeric conversion helpers. F32 values are stored as Double only AFTER a Float32 operation, a lossless widening of that already-rounded value. Every f32 arithmetic node converts its exact stored f32 operands to `Float`, executes one binary32 operation, checks finiteness and stores the rounded result. AbstractFloat operations execute as `Double` binary64 with finite checks. Comparison uses the actual type-resolved operands. Int64->f32 converts directly to Float to avoid an intermediate Double conversion; suffixed decimal literals parse directly as Float(text), not Float(Double(text)). No f16 or hexadecimal float parsing is claimed.

`ScalarConstantExpressions.swift` retains the flat typed AST. Numeric consensus permits abstractInt->abstractFloat/f32 and abstractFloat->f32; concrete integer/floating types never mix implicitly. All RHS names/types and required implicit representability are checked before lazy execution. Integer-only attributes/count/workgroup sites still require an integer result; bare float is not accepted by an attribute just because it is numerically integral. An explicit integer conversion can produce an integer result as specified.

Module and local scalar declarations now share the evaluator and annotation materialization path; old float-literal-only bypasses were removed. Abstract module floats remain frontend compile-time values. Local abstract float expressions are materialized per use and pruned by the existing boundary; concrete f32 folded values enter IR as finite f32 literals. Existing concrete named constants, source locations, dependency order and local scopes remain preserved. Literal source locations and failed assertions retain exact UTF8 ranges.

Unary negation, +-*/%, comparison/equality, scalar f32/bool/i32/u32 constructors (including zero constructors), numeric min/max/clamp and scalar select are implemented in this bounded profile. Float min/max/clamp operands are type-materialized before comparison; clamp bounds remain separately checked even on a skipped call. Eager select still evaluates both values, unlike logical short circuit.
